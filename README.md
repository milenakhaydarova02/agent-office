# Agent Office

Пиксельный офис поверх всех окон, где видно, что делает **Claude Code**: персонажи читают файлы, ищут в интернете, приводят субагентов, ждут твоего ответа. В отдельной комнате живёт локальная нейросеть Qwen (по желанию). Есть дождь, улица, кот и режим заставки.

*A pixel-art always-on-top office that shows what Claude Code is doing in real time. Windows.*

## Установка (Windows 10/11)

1. Скачай `AgentOffice-x.y.z-win-x64.zip` в [Releases](../../releases) и распакуй в любую папку.
2. Запусти `AgentOffice.exe`. Windows может предупредить о неизвестном издателе, потому что exe не подписан: нажми «Подробнее» → «Выполнить в любом случае».
3. На вопрос «Подключить офис к Claude Code?» ответь **Подключить**. В `~/.claude/settings.json` добавятся хуки (остальные настройки не трогаются, копия сохраняется в `settings.json.bak-office`).
4. Открой **новый** чат Claude Code: офис оживёт.

Node.js не нужен: exe сам служит хуком (`AgentOffice.exe --office-hook`). Если папку с офисом перенести, при следующем запуске он сам поправит путь в хуках.

## Управление

- `Ctrl+Alt+End` — показать или скрыть офис.
- Мини-игра «ИГРА» (пока Claude думает): пробел — прыжок, вниз — пригнуться, `F` — выстрел из дробовика. На дороге попадаются бустеры: **дробовик** (3 патрона, разносит препятствие) и **ракета** (несколько секунд полёта, собирает бонусы).
- Кнопки в верхней полосе: звук, масштаб, закрепить поверх окон, заставка.
- Отключить от Claude Code: `node install-hooks.js --remove` (из исходников) или удали записи с `office-hook` из `~/.claude/settings.json`.

## Настроить под себя с помощью Claude

Открой папку с исходниками в Claude Code и напиши: **«Прочитай CLAUDE-SETUP.md и настрой офис под меня»**. Claude спросит, какие нужны язык, имена персонажей, звук и комнаты, поправит код и пересоберёт exe.

## Из исходников

```bash
npm install
npm start          # запустить
npm run build      # собрать dist/AgentOffice/AgentOffice.exe и zip
node install-hooks.js   # подключить хуки через node (для запуска из исходников)
```

## Qwen (необязательно)

Комната Qwen показывает локальный llama-server (`QWEN_URL`, по умолчанию `http://127.0.0.1:9931`). Без него Qwen просто спит.
