# Agent Office: установка и настройка (инструкция для Claude)

> **Человеку:** распакуй архив в любую папку (лучше без кириллицы в пути, например `C:\agent-office`), открой эту папку в Claude Code (приложение Claude → вкладка Code, или `claude` в терминале) и напиши:
> **«Прочитай CLAUDE-SETUP.md и установи офис»**. Дальше Claude всё сделает и задаст пару вопросов.

---

## Claude, это тебе

Agent Office — это пиксельный офис в отдельном окне на Electron, поверх всех окон. В нём человечки показывают, что ты делаешь прямо сейчас: читаешь файл, ищешь в интернете, запускаешь субагентов (они приходят в офис как отдельные сотрудники), ждёшь ответа и так далее. Данные он получает от **хуков Claude Code**: `hooks/office-hook.js` отправляет события на `http://127.0.0.1:47321/event`, а окно их показывает. Если офис закрыт, хук молча выходит и ничему не мешает.

Требования: **Windows 10/11** (проверено только на Windows; на macOS и Linux окно запустится, но детектор заставки `saver-probe.ps1` работать не будет), Node.js 18+, около 350 МБ под Electron.

**Два пути:**
- **Только поставить** — человеку хватит готового `AgentOffice.exe` из GitHub Releases (см. README): Node не нужен, хуки exe подключит сам. Если человек уже так сделал, переходи сразу к шагу 5.
- **Настроить под себя** — нужны исходники (эта папка) и Node: правишь код и пересобираешь exe командой `npm run build` (результат: `dist/AgentOffice/AgentOffice.exe` и zip). После сборки закрой старый офис и запусти новый exe: он сам переподключит хуки на свой путь. Хуки на `node install-hooks.js` (шаг 3) нужны, только если офис запускают из исходников (`npm start`).

### Шаг 1. Проверь среду
- Выполни `node -v`. Если команды нет, найди node по пути `C:\Program Files\nodejs\node.exe`. Если Node вообще не установлен, **не ставь его сам**: дай человеку ссылку https://nodejs.org (версия LTS) и попроси поставить двойным кликом, потом перезапустить приложение Claude. Установщики, которые запускаешь ты, могут падать в песочнице.
- Убедись, что в пути к папке нет проблем (пробелы допустимы, а кириллицу лучше избегать).

### Шаг 2. Установи зависимости
В папке офиса выполни `npm install`. Он скачает Electron (~100 МБ архив, ~330 МБ на диске). Перед этим скажи человеку, что будет скачано и сколько это весит, и получи его согласие.

### Шаг 3. Подключи хуки
Выполни `node install-hooks.js`. Скрипт:
- добавляет офисные хуки в `~/.claude/settings.json` (глобально, поэтому офис видит работу Claude в любой папке);
- не трогает остальные настройки и чужие хуки;
- перед записью делает резервную копию `settings.json.bak-office`;
- при повторном запуске не создаёт дубли (это полезно, если папку перенесли);
- `node install-hooks.js --remove` убирает хуки.

Скрипт прописывает **абсолютный путь** к этой папке. Если человек потом переместит офис, запусти скрипт ещё раз из нового места.

Новые хуки начинают действовать **со следующей сессии Claude Code**. Текущий чат их не увидит, нужен новый.

### Шаг 4. Запусти
Запусти `start-office.bat` или `npx electron .` в фоне. Окно появится поверх остальных.
- `Ctrl+Alt+End` — показать или скрыть окно.
- Кнопки в окне: звук, масштаб, заставка.

Проверка — прогони настоящий хук тестовым событием (у Claude должен появиться пузырь «ищу в интернете погода»):
`echo {"hook_event_name":"PreToolUse","tool_name":"WebSearch","tool_input":{"query":"погода"}} | node hooks/office-hook.js`
(в PowerShell оберни JSON в одинарные кавычки и передай через `|`).

### Шаг 5. Настрой под человека
Спроси коротко, **одним сообщением**: на каком языке подписи, как назвать его Claude и команду, нужна ли комната Qwen, какой звук и какой стиль. Потом правь:

| Что | Где |
|---|---|
| Имена и внешность персонажей (CLAUDE, QWEN, команда РИК/НИНА/БО/ФИЛ/АВА/ТИМ, запасные имена) | `renderer/sprites.js`: `LOOKS`, `EXTRA_NAMES`, `PRO` |
| Реплики и шутки персонажей, прохожих | `renderer/game.js`: массивы строк (поиск по `'['`) |
| Фразы «что делает Claude» (читаю файл, ищу в интернете…) | `hooks/office-hook.js`: `SHELL` и `switch` по инструментам |
| Комнаты, цвета стен, вывески магазинов на улице | `renderer/scene.js`: `ROOMS`, `PAL`, списки вывесок |
| Громкость (дождь, фон, шаги) | `renderer/sound.js`: третье число в `setLayer(...)` — громкость |
| Горячая клавиша | `main.js`: `HOTKEY` |
| Порт | переменная окружения `OFFICE_PORT` (по умолчанию 47321; если её меняешь, задай и для хука) |

После правок `renderer/*` перезапусти окно: закрой процесс electron этой папки и запусти заново. Хук перечитывается сам при каждом событии.

### Qwen (необязательно)
Комната Qwen показывает локальную нейросеть на llama-server (`QWEN_URL`, по умолчанию `http://127.0.0.1:9931`). Если у человека её нет, Qwen просто спит в своей комнате, и это нормально. Если комната ему не нужна, можно убрать её из `ROOMS` и `qwen`-агента в `game.js`, но это заметная правка: сначала спроси. `bridge/ask-qwen.js` нужен только тем, у кого есть локальный llama-server.

### Чего не делать
- Не ставь программы установщиками сам: Node ставит человек.
- Не перезаписывай `~/.claude/settings.json` целиком, только через `install-hooks.js`.
- Не меняй таймаут хука выше нескольких секунд: хук вызывается на каждом действии Claude.

### Готово, когда
1. Окно офиса открыто.
2. В **новом** чате Claude Code у человечка Claude появляются пузыри с действиями.
3. Подписи и стиль настроены так, как попросил человек.
